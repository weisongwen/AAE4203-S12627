# UrbanNav Benchmark Inputs

This folder contains only the raw observations, the cleaned broadcast navigation file and reusable GPS preprocessing inputs. The reference trajectory used for scoring is not included.

| File | Purpose |
| --- | --- |
| `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs` | 1534 observation epochs, GPS week 2158 |
| `UrbanNav_20210521_multiGNSS_clean.nav` | Multi-constellation broadcast navigation file for the same day |
| `preprocessed_gps/` | GPS L1 inputs generated by `rinex2csv.m` from the two files above, so that Python can be run directly |

See `../Readme.md` for the quick-start commands. The navigation file contains several constellations; the teaching baseline selects GPS only.
Epochs that fail in preprocessing are kept as NaN; the Python solver omits them and records the reason in its output folder.
Do not use the navigation file of another date (for example the 2025 example) with this 2021 observation file.

Sources and cleaning details: `../docs/DATA_SOURCES.md`.
