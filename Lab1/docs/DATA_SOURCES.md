# Data and Code Sources

## Example dataset (Block X, 2025)

From the 2025 lab repository [Gao-tech1/AAE4203-lab](https://github.com/Gao-tech1/AAE4203-lab).

- The UBX log is `COM6___9600_250916_020025_blockz.ubx` in the `Lab1` folder.
- The example OBS/NAV files, the five input CSV files, the receiver reference, the POS/KML files and the archived results are in `dataset/`.
- Recording time: 2025-09-16 02:00:54.006 to 02:03:59.006 GPST, 186 epochs.
- `epochs.csv` is extracted from the matching OBS file, not inferred from row numbers or dates. Submissions use a 0.1 s time grid.
- `dataset/reference_results/` keeps the results of the original author; reproducing them numerically does not independently validate every physical model of the original algorithm.
- The archived CSV files carry no satellite IDs or constellation labels, so they are not claimed to be GPS-only.

The six numerical functions of the original Python solver are kept unchanged in `tools/legacy_solver.py`; the entry point `WLSE_spp.py` adds arguments, time matching, data checks and separate output folders.
The original scripts are kept in `legacy/` for comparison.

## UrbanNav benchmark

[UrbanNav project](https://github.com/IPNL-POLYU/UrbanNavDataset#urbannav-hk-deep-urban-1).

- `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs`: 1534 epochs.
- GPST: 2021-05-21 06:29:06.004 to 06:54:39.005, GPS week 2158.
- The UrbanNav project publishes its ground truth, but this package neither includes nor reads the reference file used by the teaching team for scoring.
- Benchmark results are evaluated by the teaching team's scoring system; the dataset itself is public and is not a confidential test set.

## Navigation file

The benchmark navigation file is not the 2025 example navigation file. It merges and cleans the GPS, GLONASS, Galileo and BeiDou broadcast navigation records of the HK SatRef station HKSC for day 141 of 2021 (Lands Department, HKSAR).

Source: [HK SatRef RINEX download](https://www.geodetic.gov.hk/en/rinex/ftp_RINEX.htm).

SHA256 of `UrbanNav_20210521_multiGNSS_clean.nav`:

```text
38c83f4007aab06a88074591054d511a4b132c2798ad90d85d7ead4bfca7cf88
```

Cleaning removed malformed blank lines, unified LF line endings and kept one 18 s leap-second record of the GPS reference; the broadcast orbit values were not refitted or modified.
The file contains several constellations; this does not mean that the GPS baseline implements multi-constellation positioning.

`benchmark/preprocessed_gps/` was generated by `rinex2csv.m` from the included OBS/NAV files.
The settings and the input hashes are recorded in `benchmark/preprocessed_gps/manifest.json`.

## Third-party code and course documents

- The original teaching code keeps the 2025 MIT `LICENSE` of GAO Yixin.
- [MatRTKLIB](https://github.com/taroz/MatRTKLIB) is included with its author notes and licence. The CSV files originally in `matRTKLIB/+gt/` are kept; the runnable entry points use explicit input folders and do not read them.
- The CSV checker checks the five standard columns, 3-decimal coordinates, finite values, time order, duplicate epochs and coverage of the observation times, and keeps the course checks of the group file name and of the position near the Earth's surface. It is not the online scoring server.
- The online format rules were compared with `PolyU-TASLAB/AAE4203_ASN_2026/app/submission.py` (blob SHA `facc63595de9a46bc76deb2cbe8fccb8686a07fc`); the server code is not copied into this package.
- The original course versions of the converter and the checker are kept as `legacy/rinex2csv_course_original.m` and `legacy/check_submission_course_original.py`.
- The report template is the version provided by the lecturer; the tutorial and Blackboard remain the authoritative source of the course requirements.
- The code licence grants no additional rights to the UrbanNav data, the HK SatRef data or the teaching documents; their own terms of use apply, and they should be cited.
